## Positives

- Native renderer
- Widescreen support
- Interpolated frames / smooth motion
- Texture pack compatibility
- Multi-platform support
- PCSX2 save file compatibility
- Expanded in-game options / UI

## Negatives

- Limited game version support: only certain releases are functional, including EU, KR, and JP releases, with the US release being the exception.
- In active development: as with most projects like this, bugs and technical issues are expected.

## Worth Running? Yes

Still in development, but the devs are clear about their intent and updates seem steady. Overall, it’s a strong effort and looks like a 1.0 release isn’t too far away.
