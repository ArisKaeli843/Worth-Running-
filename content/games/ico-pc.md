## Positives

- Native Renderer
- Widescreen support
- Interpolated Frames / Smooth Motion
- Texture pack compatibility
- Multi-platform support
- PCSX2 save files compatible
- Expanded in-game options / UI

## Negatives

- Limited game version support: only certain releases are functional, including EU, KR and JP, with the US release being the exception.
- In active development: as with most releases like this, bugs and technical issues are expected.

## Worth Running? fuck yes

Personally, I was very happy with this release. It works great, and it’s clear the devs gave a damn. So go ahead and have fun — I guess.
